## Что означает «100%»

Для каждой страницы множество чисел в текстовом слое PDF сравнивается с множеством чисел в
выгрузке. Если число исходника не встречается в `deck.json` этой страницы — это пропуск.
Во всех семи колодах пропусков нет.

## Что проверено дополнительно

- Контрольные страницы сверялись с рендером вручную: доли каналов, панели «Деньги/Упаковки»,
  регионы, стековые диаграммы, сегментные списки, линейные графики.
- Арифметика внутри однородных групп: суммы долей ≈ 100, иерархии сегментов сходятся
  (например, РОМИР, сл. 41: 32,3 = 12,9 + 19,4), «деньги = инфляция + спрос + количество магазинов».
- Отсутствие дублирующихся подписей внутри одной таблицы.

## Чего проверка не гарантирует

- Осмысленность пары, если на слайде две разные метрики рядом: привязка сделана по геометрии,
  а не по смыслу. На таких слайдах в `note` написано, как именно читали.
- Точность глазомерного чтения графиков без подписей (±0,5 для ЭКОПСИ).
