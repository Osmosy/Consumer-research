# ЭКОПСИ — Дебаты про поколения

Машинно-читаемая расшифровка `ЭКОПСИ_Дебаты_про_поколения.pdf` (21 стр.).

## Файлы

| Файл | Что это |
|---|---|
| `ekopsi-debaty-pro-pokoleniya.md` | текст по слайдам: заголовок, абзацы, таблицы «показатель → значение», сноски |
| `index.html` | то же с картинками слайдов, оглавлением и поиском |
| `deck.json` | структура в JSON: 21 слайдов, 26 строк таблиц |
| `slides/` | рендеры слайдов 1500 px |
| `ekopsi-debaty-pro-pokoleniya.pdf` | печатная версия |
| `VERIFICATION.md` | что и как проверено |

## Как устроено

- Текст и числа — из текстового слоя PDF (без OCR), поэтому цифры точные.
- Таблицы «показатель → значение» собраны по координатам и **сверены с рендером страницы**
  (13 слайдов размечены вручную в `kit/ovr/ekopsi-debaty-pro-pokoleniya.py`).
- Покрытие чисел: 227 из 227 (100%).

## Как читать

```python
import json
d = json.load(open("deck.json"))
s = d["slides"][2]
s["title"], s["blocks"], s["table"]
```

Поля слайда: `page`, `title`, `blocks[]` (`kind`: `p`|`li`|`h`), `table[]` (`label`,`value`),
`footnotes[]`, `note`, `words`.
