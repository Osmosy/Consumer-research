# Исследования потребителя

Семь презентаций о потребительском рынке, переведённые в машинно-читаемый вид: текст по слайдам,
таблицы «показатель → значение», JSON, рендеры слайдов. Всё, что нужно для анализа, лежит в
открытых форматах — без PowerPoint и без OCR-догадок.

- Колод: **7**, слайдов: **260**, строк данных: **2758**.
- Числа взяты из текстового слоя PDF. Каждое число исходника присутствует в выгрузке — проверено скриптом.
- Привязка «какая подпись владеет каким числом» сделана постранично и сверена с рендером страницы.

## Что внутри папки колоды

| Файл | Назначение |
|---|---|
| `<slug>.md` | полный текст по слайдам: заголовок, абзацы, таблицы, сноски |
| `deck.json` | та же структура для кода: `meta` + `slides[]` |
| `index.html` | просмотр с картинкой каждого слайда, оглавлением и поиском |
| `slides/NN.jpg` | рендер слайда 1500 px — сверить цифру глазами |
| `<slug>-print.pdf` | печатная версия выгрузки |
| `README.md`, `VERIFICATION.md`, `llms.txt` | метод, протокол проверки, точка входа |

## Схема `deck.json`

```jsonc
{
  "meta": {"source": "файл.pdf", "title": "...", "pages": 47, "schema": "unified-1"},
  "slides": [{
    "page": 11,                       // номер слайда в исходном PDF, 1-based
    "section": "Общий U&A",          // раздел колоды, если он есть
    "title": "Уровень стресса",      // заголовок слайда
    "blocks": [{"kind": "p|li|h", "text": "..."}],   // абзацы, списки, подзаголовки
    "table":  [{"label": "...", "value": "...", "panel": "РФ", "quotes": "..."}],
    "panels": [{"header": "РФ", "rows": [...]}],     // исходное деление на панели (РФ/РБ, Деньги/Упаковки)
    "footnotes": ["Источник: ..."],
    "note": "что прочитано с картинки и что в исходнике дефектно",
    "source_layer": "vector-text | raster | curated"
  }]
}
```

`panel` есть только там, где слайд делится на панели (например, РФ и РБ). `quotes` — цитаты
респондентов, привязанные к строке таблицы (в колоде Инкофуда).

## Как цитировать

Ссылка на факт: `deck=<slug>, page=<N>` — этого достаточно, чтобы найти слайд в
`decks/<slug>/slides/NN.jpg` и проверить значение глазами.

## Границы достоверности

- Числа, стоявшие в текстовом слое PDF, точны — они не перепечатывались.
- Числа, которые в презентации вставлены картинкой (диаграммы, крупные плашки), прочитаны
  с рендера 2400 px; на таких слайдах в `note` это указано.
- Линейные графики без подписей значений (ЭКОПСИ) прочитаны глазомерно, точность ±0,5 —
  в таблице значения с «≈».
- Дефекты самих презентаций (незаполненные заглушки «[ЗНАЧЕНИЕ]», битые шрифты,
  неподписанные сегменты, дубли слайдов) зафиксированы, а не исправлены молча.
  Полный список — [`docs/caveats.md`](docs/caveats.md).
