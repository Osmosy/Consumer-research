# Инкофуд — «Исследование потребителя», октябрь 2026

Машинно-читаемая расшифровка презентации `InkofoodRepOct2026.pdf` (69 слайдов, Keynote → PDF, 1920×1080).
Сделано для агентов и людей: одна и та же структура в трёх форматах.

## Что внутри

| Файл | Что это | Для кого |
|---|---|---|
| `inkofood-2026.md` | полный текст колоды: раздел → слайд → панели РФ/РБ → таблицы → комментарии автора | LLM, поиск, diff, git |
| `index.html` | тот же текст + картинка каждого слайда, боковое оглавление, поиск по тексту | человек в браузере |
| `deck.json` | та же структура в JSON (69 объектов, 763 строки данных) | скрипты, RAG, пайплайны |
| `slides/01.jpg … 69.jpg` | рендеры слайдов 1500×844 | визуальная сверка |
| `inkofood-2026.pdf` | печатная версия HTML (A4, landscape) | офлайн-чтение |

## Метод и точность

Слои данных в этой колоде разные, и обработаны они по-разному:

1. **Векторный текст PDF (основной слой).** Keynote экспортирует текст как вектор, поэтому он читается
   точно: 709 чисел и все подписи взяты из самого PDF, без OCR. Строки «показатель → значение»
   собраны по координатам (значение справа по строке или над столбцом) — это единственный вывод,
   который делает скрипт.
2. **Растровые панели.** На 9 слайдах (42, 44–46, 49, 50, 54, 58, 62) диаграммы и облака слов
   вставлены картинками: их текст отсутствует в PDF. Они прочитаны по рендеру 2400 px и помечены
   в тексте слайда.
3. **Сверка.** Для всех 69 слайдов проверено, что каждое число из текстового слоя PDF присутствует
   в выгрузке: 709 из 709 (100%). Для распределений проверены суммы долей (должны давать 100%).

Полный отчёт о проверке: [`VERIFICATION.md`](VERIFICATION.md).

## Как пользоваться

Агент, читающий `deck.json`:

```python
import json
deck = json.load(open("deck.json"))
s = deck["slides"][5]              # слайд 6
s["title"]                          # "Драйверы выбора"
for panel in s["panels"]:           # [{"header": "РФ"|"РБ", "rows": [...]}]
    for row in panel["rows"]:
        print(panel["header"], row["label"], row["value"])
```

Поля слайда: `page`, `section`, `title`, `note`, `panels[]`, `comments[]`, `paragraphs[]`,
`source_layer` (`vector-text` | `raster-read` | `curated`), `values`, `n_rows`.
Строка таблицы: `label`, `value`, опционально `value2`, `quotes`, `note`.

Поиск по Markdown: `grep -n "Брест\|Natura\|45,8" inkofood-2026.md`.

## Известные дефекты исходной презентации

Они не исправлены, а зафиксированы — так, как напечатаны:

- слайд 45 дублирует слайд 44 (те же данные и комментарий);
- слайд 12 набран без заголовка — это стена цитат;
- слайд 42 без заголовка: фраза внизу — комментарий автора, а не заголовок;
- слайд 53 (РБ) и слайд 57 (РФ): у одного столбца диаграммы отсутствует подпись процента
  (в 57-м значение восстановлено как остаток до 100% и помечено);
- слайд 66: последняя подпись столбца — «Untitled 1» (незакрытый слой Keynote);
- слайд 63: в комментарии опечатка «Дина» вместо «Длина» — сохранена дословно;
- слайд 30 (обе панели) и слайд 44 (РБ): суммы долей не равны 100% (97,0 / 98,5 и 101,0) —
  пропуски и округление в исходных данных; слайды 5 и 66 — 99,2–99,9% в пределах округления;
- орфография респондентов в цитатах сохранена («брент», «Плесинь», «отглосоаки»).
