# Gartner — Top 10 Strategic Tech Trends 2027

Машинно-читаемая расшифровка `Gartner_Top 10 Strategic Tech Trends_2027 (28 pgs).pdf` (28 стр.).

## Файлы

| Файл | Что это |
|---|---|
| `gartner-tech-trends-2027.md` | текст по слайдам: заголовок, абзацы, таблицы «показатель → значение», сноски |
| `index.html` | то же с картинками слайдов, оглавлением и поиском |
| `deck.json` | структура в JSON: 28 слайдов, 19 строк таблиц |
| `slides/` | рендеры слайдов 1500 px |
| `gartner-tech-trends-2027.pdf` | печатная версия |
| `VERIFICATION.md` | что и как проверено |

## Как устроено

- Текст и числа — из текстового слоя PDF (без OCR), поэтому цифры точные.
- Таблицы «показатель → значение» собраны по координатам и сверены с рендером страницы
  (10 слайдов размечены вручную).
- Покрытие чисел: 174 из 174 (100%).

import json
