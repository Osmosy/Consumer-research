# РОМИР — Тренды покупательского поведения 2026

Машинно-читаемая расшифровка `РОМИР_Тренды_покупательского_поведения_2026_47_стр.pdf` (47 стр.).

## Файлы

| Файл | Что это |
|---|---|
| `romir-trendy-2026.md` | текст по слайдам: заголовок, абзацы, таблицы «показатель → значение», сноски |
| `index.html` | то же с картинками слайдов, оглавлением и поиском |
| `deck.json` | структура в JSON: 47 слайдов, 337 строк таблиц |
| `slides/` | рендеры слайдов 1500 px |
| `romir-trendy-2026.pdf` | печатная версия |
| `VERIFICATION.md` | что и как проверено |

## Как устроено

- Текст и числа — из текстового слоя PDF (без OCR), поэтому цифры точные.
- Таблицы «показатель → значение» собраны по координатам и **сверены с рендером страницы**
  (39 слайдов размечены вручную в `kit/ovr/romir-trendy-2026.py`).
- Покрытие чисел: 384 из 384 (100%).

## Как читать

```python
import json
d = json.load(open("deck.json"))
s = d["slides"][2]
s["title"], s["blocks"], s["table"]
```

Поля слайда: `page`, `title`, `blocks[]` (`kind`: `p`|`li`|`h`), `table[]` (`label`,`value`),
`footnotes[]`, `note`, `words`.
