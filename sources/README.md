# Исходные PDF

По умолчанию их в репозитории нет — только манифест с sha256 и путями: презентации вместе весят ~80 МБ,
а для проверки происхождения достаточно хэша. Если нужен полный архив, скопируйте файлы из путей
`original_path` в эту папку и добавьте через `git add -f sources/*.pdf`.

Исключение — **опросник** [`pdf/Маркетинговое исследование Инко Фуд, онлайн панель 900 респондентов.pdf`](pdf/):
932 КБ, анкета целиком, полезна вместе с выгрузкой (по ней видно вёрстку, шкалы и визуалы упаковок).
Хэш тот же, что в `manifest.json`, — файл в репозитории можно сверить с ним.
