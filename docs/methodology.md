# Метод

1. **Текстовый слой PDF — основной источник.** Keynote и PowerPoint экспортируют текст как вектор,
   поэтому заголовки, абзацы, сноски и подписи читаются точно, без OCR и без перепечатки.
   Числа берутся из этого слоя с координатами.
2. **Абзац = текстовый блок PDF.** Порядок чтения: блоки раскладываются по колонкам
   (кластеризация по левому краю, допуск ~70 px), внутри колонки — сверху вниз. Это сохраняет
   двух- и трёхколоночные слайды.
3. **Таблицы собираются по координатам.** Пара «подпись → значение» определяется по близости
   (одна строка, один столбец, плашка под числом). Таблица выводится только при однозначной
   привязке: если часть чисел не находит подпись, они перечисляются отдельно — лучше сырой список,
   чем число, приписанное не тому показателю.
4. **Растровые панели читаются отдельно.** Диаграммы, вставленные картинкой, рендерятся в 2400 px
   и читаются глазами по рендеру; на слайде это отмечено в `note`. Серии, у которых подписи только
   в легенде, сопоставляются по цвету заливки из векторной графики PDF.
5. **Проверка.** Скрипт сравнивает множество чисел текстового слоя PDF с тем, что попало в выгрузку
   (страница за страницей). Расхождение = пропущенное число. Во всех семи колодах — 100%.
6. **Дефекты исходника фиксируются**, а не исправляются: пустые заглушки, битые шрифты,
   неподписанные сегменты, дубли слайдов перечислены в `docs/caveats.md` и в `note` слайдов.
