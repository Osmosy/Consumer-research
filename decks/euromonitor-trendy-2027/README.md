# Euromonitor — Top Global Consumer Trends 2027

Машинно-читаемая расшифровка `Euromonitor_Top Global Consumer Trends_2027 (67 pgs).pdf` (67 стр.).

## Файлы

| Файл | Что это |
|---|---|
| `euromonitor-trendy-2027.md` | текст по слайдам: заголовок, абзацы, таблицы «показатель → значение», сноски |
| `index.html` | то же с картинками слайдов, оглавлением и поиском |
| `deck.json` | структура в JSON: 67 слайдов, 6 строк таблиц |
| `slides/` | рендеры слайдов 1500 px |
| `euromonitor-trendy-2027.pdf` | печатная версия |
| `VERIFICATION.md` | что и как проверено |

## Как устроено

- Текст и числа — из текстового слоя PDF (без OCR), поэтому цифры точные.
- Таблицы «показатель → значение» собраны по координатам и сверены с рендером страницы;
  сколько слайдов размечено вручную и где числа остались перечислением — в `VERIFICATION.md`.
- Покрытие чисел: 544 из 544 (100%).

import json
