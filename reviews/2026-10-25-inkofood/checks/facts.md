# facts.csv — машиночитаемый факт-лист разбора

Вход для прогонов в Vector Marketing и для любой другой модели, которой нужно работать по этой колоде.
Собран механически из `verify_claims.py` — единственного источника истины для счёта, поэтому номера
строк совпадают с `checks.csv` и приложением A пояснения.

```
91 проверка  →  facts.csv          88 строк (83 дословных + 5 с оговоркой)
                facts-rejected.csv  3 строки — что утверждать нельзя
                facts-summary.json  счёт по колодам, блокам и форме записи
```

## Колонки facts.csv

| Колонка | Что в ней |
|---|---|
| `id` | номер проверки в `verify_claims.py` (1–91) |
| `block` | Демография, Драйверы, Бренды, Макро, Продукт, Поколения |
| `claim` | что утверждал агент — по этой формулировке удобно искать |
| `fact` | что стоит в колоде дословно |
| `value_ru` | первое число пары «РФ / РБ», если пара есть |
| `value_by` | второе число пары (РБ) |
| `unit` | `%`, если в источнике проценты |
| `pairs` | все пары «РФ/РБ» через `;` — в одной строке их бывает до двенадцати (репертуар, барьеры) |
| `numbers` | все числа строки по порядку, без повторов |
| `shape` | `пара` (36 строк), `числа` (51), `текст` (1) — чтобы не читать счётчики и суммы как пару стран |
| `deck` | папка колоды, например `inkofood-2026` |
| `page` | страница или страницы как в источнике: `5`, `5, 11, 13`, `14-15` |
| `page_num` | первая страница числом — для сортировки |
| `verdict` | `подтв.` (83) или `подтв.*` (5) |
| `agent` | кто это утверждал: A1 Клод (18), A2 Грок (5), A3 Гемини (65) |
| `note` | оговорка у пяти строк `подтв.*` |

## facts-rejected.csv

Три утверждения, которые колода не подтверждает. Их нельзя использовать в тексте, но нужно
показывать агенту заранее — иначе он повторит:

| № | Что утверждали | Что в колоде |
|---|---|---|
| 24 | «Без нитритной соли» как преимущество | 60,7 / 58,7% считают это маркетингом (`inkofood-2026, page=42`) |
| 25 | Поколенческие различия в ценностях | «Отличий между поколениями нет» (`ekopsi-debaty-pro-pokoleniya, page=19`) |
| 87 | 58% ориентируются на курируемые предложения | на `page=16` чисел нет; 58% — `page=22` и `page=26` |

## Как этим пользоваться в прогоне

Не пересказывать таблицу, а передавать её файлом или её выжимкой — вместе с правилом:

```
Факты — в facts.csv (88 строк, адреса deck/page). Правила:
1. Использовать только числа из facts.csv, ничего не добавлять.
2. Каждое число сопровождать адресом deck=<папка>, page=<N>.
3. Если строки в facts.csv нет — сказать «данных нет», а не оценивать.
4. facts-rejected.csv — список запрещённых утверждений, повторять их нельзя.
5. В конце перечислить, каких данных не хватает для решения.
```

Отбор под задачу: `shape=пара` — когда нужны обе страны; `block=Бренды` — battlecard;
`block=Продукт` — упаковка, цена, ГОСТ; `block=Макро` — рынок и смежные колоды.

## Пересборка

```bash
python3 build_facts.py                  # только печать счёта
python3 build_facts.py --write .        # записать три файла в текущий каталог
```

Скрипт читает `verify_claims.py` рядом с собой и не содержит абсолютных путей: при правке проверок
достаточно перезапустить его, чтобы `facts.csv` не разошёлся с `checks.csv`.
