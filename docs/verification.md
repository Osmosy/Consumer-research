## Что означает «100%»

Для каждой страницы множество чисел в текстовом слое PDF сравнивается с множеством чисел в выгрузке.
Если число исходника не встречается в `deck.json` этой страницы — это пропуск.

## Пять колод партии 21.11: где числа не привязаны к подписям

В этих колодах часть слайдов — диаграммы, где подписи серий и значений не сходятся в пары по координатам
(многорядные и стековые бары, легенда отдельно, шкалы без подписей серий). По решению от 21.11 такие
слайды не вычитывались по рендеру: значения сохранены перечислением в порядке PDF, в `note` слайда
написано, что данные — в диаграмме. Числа при этом не потеряны, но структура «подпись → значение» не

## Что проверено дополнительно

- Контрольные страницы сверялись с рендером вручную: доли каналов, панели, регионы, стековые диаграммы,
  линейные графики, таблицы с шапкой.
- Арифметика внутри однородных групп: суммы долей ≈ 100, иерархии сегментов сходятся.
- Отсутствие дублирующихся подписей внутри одной таблицы.

## Чего проверка не гарантирует

- Осмысленность пары, если на слайде две разные метрики рядом: привязка сделана по геометрии.
- Точность значений, которые в исходнике есть только на диаграмме: они не вычитывались (см. раздел выше).
