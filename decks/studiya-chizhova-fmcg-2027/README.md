## Как устроено

- Страница 15 и 16 — обычный текстовый слой PDF; остальные 31 — изображения.
- Изображения прочитаны двумя способами: 19 страниц — OCR (tesseract 5.5, rus+eng, 400 dpi,
  сверка с прогоном 300 dpi), 12 страниц — чтение по рендеру слайда (там, где OCR давал
  низкую уверенность: тёмный фон, стилизованные шрифты).
- Способ чтения указан в поле `note` каждой страницы.
- Ручной вычитки всего текста не было: в OCR-страницах возможны ошибки распознавания.
- Таблиц «показатель → значение» нет: пары «подпись → число» на этих страницах не восстанавливались,
  числа остались в тексте строк.
- Покрытие чисел текстового слоя: 25 из 25 (это только две текстовые страницы; остальные
  страницы в эту проверку не входят по определению).
