# NTech — Годовая конференция 2026

Машинно-читаемая расшифровка `NTech. Годовая конференция 2026..pdf` (106 стр.).

## Файлы

| Файл | Что это |
|---|---|
| `ntech-konferenciya-2026.md` | текст по слайдам: заголовок, абзацы, таблицы «показатель → значение», сноски |
| `index.html` | то же с картинками слайдов, оглавлением и поиском |
| `deck.json` | структура в JSON: 106 слайдов, 400 строк таблиц |
| `slides/` | рендеры слайдов 1500 px |
| `ntech-konferenciya-2026.pdf` | печатная версия |
| `VERIFICATION.md` | что и как проверено |

## Как устроено

- Текст и числа — из текстового слоя PDF (без OCR), поэтому цифры точные.
- Таблицы «показатель → значение» собраны по координатам и сверены с рендером страницы
  (77 слайдов размечены вручную).
- Покрытие чисел: 955 из 955 (100%).
