# Нильсен — Как найти путь к покупателю

Машинно-читаемая расшифровка `Нильсен_Как_найти_путь_к_покупателю.pdf` (30 стр.).

## Файлы

| Файл | Что это |
|---|---|
| `nielsen-put-k-pokupatelyu.md` | текст по слайдам: заголовок, абзацы, таблицы «показатель → значение», сноски |
| `index.html` | то же с картинками слайдов, оглавлением и поиском |
| `deck.json` | структура в JSON: 30 слайдов, 191 строк таблиц |
| `slides/` | рендеры слайдов 1500 px |
| `nielsen-put-k-pokupatelyu.pdf` | печатная версия |
| `VERIFICATION.md` | что и как проверено |

## Как устроено

- Текст и числа — из текстового слоя PDF (без OCR), поэтому цифры точные.
- Таблицы «показатель → значение» собраны по координатам и сверены с рендером страницы
  (16 слайдов размечены вручную).
- Покрытие чисел: 513 из 513 (100%).

## Как читать

```python
import json
d = json.load(open("deck.json"))
s = d["slides"][2]
s["title"], s["blocks"], s["table"]
```
